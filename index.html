Team rules

Every session this team starts or resumes from now on follows these rules, together with its own role. Sessions already running keep what they started with.

Hand off this work

The session writes a handoff brief (goal, what's done, what's left, next steps) into a .cerebro folder in its project. When the brief is ready, the receiving session reads it and carries on.

Loop this session

Sends a message again and again, so the session keeps working without you. It stops when the stop text shows up, or after the number of runs you set.

    Use SVG refraction?

    SVG refraction bends everything behind the glass, including other boxes and terminal text. It uses much more graphics power than WebGL, especially with many sessions or a large window.

    A PC with a dedicated graphics card is recommended. If the board feels slow, switch back to WebGL.
